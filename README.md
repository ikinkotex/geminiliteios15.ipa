# ✨ Gemini Lite для iOS 15.8.7 (iPhone 7 Plus)

> **Полноценный клиент Google Gemini, созданный специально для старых версий iOS (включая iOS 15.8.7 на iPhone 7 / 7 Plus), где официальное приложение недоступно.**

---

## 🎨 Дизайн и Особенности

- **Минимализм и серо-синяя палитра (Slate & Electric Blue)**: Стильный премиальный темный интерфейс (`#0B0F19`, `#131C2E`, `#3B82F6`), идеально оптимизированный под экран Retina iPhone 7+.
- **Мультимодальность**:
  - Отправка только текстового вопроса.
  - Отправка фото прямо с камеры (фотографируйте страницы учебника, конспекты, доску в классе).
  - Выбор фотографий или скриншотов из галереи (поддерживается прикрепление нескольких фото одновременно).
  - Отправка вопроса вместе с фото или только фото (нейросеть автоматически поймет задание).
- **Свой API ключ**:
  - Удобный ввод и надежное сохранение в памяти устройства.
  - Кнопка **«Проверить ключ»** прямо в настройках для проверки связи с серверами Google.
  - Бесплатный ключ берется за 1 минуту в [Google AI Studio](https://aistudio.google.com/app/apikey).
- **Выбор и ввод любой модели**:
  - Быстрые пресеты:
    - ⚡ `gemini-2.0-flash` — новейшая, сверхбыстрая и точная.
    - 🚀 `gemini-2.0-flash-lite` — экономичная по трафику и мгновенная.
    - 🛡 `gemini-1.5-flash` — проверенная стабильная модель.
    - 🧠 `gemini-1.5-pro` — для сложных олимпиадных задач, высшей математики и эссе.
  - **Ручной ввод модели**: можно включить переключатель и ввести любое название (например, `gemini-2.5-flash` или экспериментальную модель).
- **Системный промпт (System Instruction)**:
  - Можно оставить **полностью пустым** (нейросеть работает стандартно).
  - Либо выбрать готовые учебные профили:
    - 🎓 **Умный репетитор**: пошаговое объяснение формул, хода решения и выделение ответа.
    - 🔍 **Проверка решений**: поиск ошибок в домашней работе и объяснение, как исправить.
    - 📝 **Краткий конспект**: выжимка определений и формул без воды.
    - 💻 **IT-Ментор & Код**: написание и объяснение чистого кода.
- **Инструменты для учебы («Имба для уроков»)**:
  - Быстрые кнопки над строкой ввода: *«Реши задачу»*, *«Найди ошибку»*, *«Объясни просто»*, *«Конспект»*, *«Перевод»*, *«Код»*.
  - Поддержка Markdown: выделение формул, списков, жирного шрифта.
  - Блоки кода с моноширинным шрифтом и отдельной кнопкой **«Копировать код»**.
  - Копирование ответа целиком и отправка в заметки/мессенджеры через системное меню «Поделиться».
  - Тактильный отклик (haptic feedback) при нажатиях.

## 🚀 Как скомпилировать в .IPA файл (Бесплатно через облако GitHub Actions)

Поскольку сборка iOS приложений требует SDK от Apple (которое поставляется только с macOS), в проект встроен автоматический сценарий для **GitHub Actions** (`.github/workflows/build-ipa.yml`). Облачный Mac собирает проект за 2 минуты:

### Шаг 1: Создайте репозиторий на GitHub
1. Зайдите на [github.com/new](https://github.com/new)
2. Назовите репозиторий (например, `gemini-lite-ios`). Сделайте его **Public** (для безлимитной бесплатной сборки) или **Private**.
3. Нажмите **Create repository**.

### Шаг 2: Отправьте код в репозиторий
Откройте PowerShell в папке с проектом и выполните две команды (замените `ВАШ_ЛОГИН` на ваш никнейм на GitHub, например `surgutovi4`):

```powershell
git remote add origin https://github.com/ВАШ_ЛОГИН/gemini-lite-ios.git
git branch -M main
git push -u origin main
```

### Шаг 3: Скачайте готовый .IPA
1. На странице вашего репозитория на GitHub перейдите во вкладку **Actions**.
2. Вы увидите запущенную сборку **«Build Gemini Lite IPA»**.
3. Через 2-3 минуты сборка завершится зеленой галочкой.
4. Откройте сборку и в разделе **Artifacts** скачайте архив с файлом **`GeminiLite.ipa`**!

## 📲 Как установить .IPA на iPhone 7 Plus (iOS 15.8.7)

### Вариант 1: Через Sideloadly (Самый простой для Windows)
1. Скачайте бесплатную программу [Sideloadly](https://sideloadly.io/) для Windows.
2. Подключите iPhone 7 Plus к компьютеру проводом Lightning.
3. Перетащите скачанный `GeminiLite.ipa` в окно Sideloadly.
4. Введите свой Apple ID в поле `Apple ID`.
5. Нажмите **Start**. Sideloadly подпишет приложение и установит его прямо на телефон.
6. На iPhone перейдите в: **Настройки ➔ Основные ➔ VPN и управление устройством**, нажмите на ваш Apple ID и выберите **«Доверять»**.

### Вариант 2: Через TrollStore 2 (Навсегда без отзыва сертификатов!)
> 🔥 **На заметку**: iPhone 7 Plus на iOS 15.8.7 базируется на процессоре A10 и уязвим к эксплойту CoreTrust. Это позволяет установить **TrollStore 2**, после чего вы сможете устанавливать любые `.ipa` прямо с телефона в 1 клик, и они **никогда не будут требовать переподписи каждые 7 дней**!
- Если у вас уже есть TrollStore: просто перешлите `GeminiLite.ipa` на телефон (через Telegram/AirDrop) и выберите «Открыть в TrollStore».

### Вариант 3: Через AltStore
- Установите AltServer на ПК и установите приложение через AltStore.

## ⚡ Бонус: Мгновенная Web-версия (PWA) без компьютера

Если вам нужно воспользоваться нейросетью прямо сейчас, не подключая телефон к ПК:
1. В папке `WebApp/` находится файл `index.html`.
2. Запустите локальный сервер или загрузите папку на GitHub Pages / Vercel.
3. Откройте страницу в **Safari на iPhone 7 Plus**.
4. Нажмите кнопку «Поделиться» (квадрат со стрелочкой) ➔ **«На экран "Домой"»**.
5. На рабочем столе появится иконка Gemini Lite. Приложение открывается на весь экран без рамок браузера, поддерживает камеру, загрузку фото, историю и точь-в-точь повторяет серо-синий нативный интерфейс!
